# PorishkarBD — Smart Waste Management & Recycling Platform

A MERN-based platform for waste reporting, collection scheduling, and recycling in Bangladesh.

## Structure

- `client/` — React frontend (Vite, Tailwind)
- `server/` — Express backend (MongoDB, MVC)

## 🔑 Login Credentials / Access Instructions

- Visit the live application: https://porishkar-bd.vercel.app/
- New users can register using the Sign Up option.
- Existing users can log in using their registered email and password.
- No predefined credentials are required for regular users.
